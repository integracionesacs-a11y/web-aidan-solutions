# Reglas técnicas - A\DAN SOLUT\ONS
Objetivo: mantener consistencia y evitar mezclar tecnologías o frameworks.

- **Frontend Core**: React 18+ (TypeScript siempre estricto).
- **Estilos**: Tailwind CSS con paleta Dark Tech (`#0B0F19`, `#00D2FF`, `#0051FF`, `#161D2F`).
- **3D & Interactividad**: Three.js acelerado (WebGL), canvas procedural o modelos low-poly con wireframe emisivo y partículas.
- **Tipografías**: Space Grotesk (Titulares), Inter (Cuerpo), JetBrains Mono (Acentos técnicos/código).
- **Iconografía**: Lucide React.
- **Microinteracciones**: Canvas-confetti, efectos glassmorphism, resplandor neón volumétrico y tilt 3D.
- **Regla estricta**: No usar Bootstrap ni jQuery. Código modular, tipado, limpio y mantenible.
