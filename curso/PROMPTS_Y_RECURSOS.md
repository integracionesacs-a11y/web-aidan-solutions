## 🤖 1. Prompts de Copywriting & Estructura de Marca

### Prompt 1: Generación de Propuesta de Valor y Hero Copy (Dark Tech)
```text
Actúa como un Director Creativo y Copywriter Senior especializado en empresas B2B de tecnología y automatización con IA.
Mi empresa se llama "A\DAN SOLUT\ONS" y nos enfocamos en digitalizar negocios para que puedan:
1) Vender más
2) Ahorrar tiempo
3) Tener el control operativo

Diseña:
- Un lema principal contundente y memorable (ejemplo: "Del caos operativo al piloto automático").
- Un titular principal para el Hero con estructura para efecto Typewriter ("Digitaliza tu negocio para [beneficio]").
- Un subtítulo de máximo 25 palabras orientado a dolor y solución directa sin jerga vacía.
- Textos para 2 botones de llamado a la acción (uno principal de diagnóstico y otro secundario para explorar).
```

### Prompt 2: Casos de Éxito y Métricas B2B de Alto Impacto
```text
Redacta 4 casos de éxito concretos para una consultora tecnológica en el sector de Telecomunicaciones y Empresas de Servicios (empresas tipo Entel, WIN, ISPs).
Para cada caso incluye:
1. Nombre del cliente y etiqueta de industria.
2. Título de la solución técnica (ej. Portal de Gestión Masiva, Agente de Soporte NOC).
3. Desafío operativo previo.
4. Solución implementada (tecnologías: Python, React, RPA, LLMs).
5. Métrica cuantificable de resultado (ej. -80% tiempo de liquidación, 99.9% uptime).
```

## 🎨 2. Prompts de Identidad Visual y Vectorización (SVG)

### Prompt 3: Generación del Isotipo / Mascota Geométrica Neón
```text
Crea una descripción técnica para generar una mascota corporativa de un puercoespín geométrico estilo low-poly cyberpunk.
Características:
- Líneas de contorno neón cyan (#00D2FF) brillantes con doble trazo (tubo neón).
- Silueta lateral orientada a la derecha, con espinas inclinadas hacia atrás coincidentes con la barra invertida '\'.
- Red interna de polígonos triangulares que simulan un circuito o nodo neuronal.
- Fondo oscuro transparente.
```

## 💻 3. Prompts de Desarrollo Frontend (HTML / CSS / JS)

### Prompt 4: Sistema de Diseño Dark Tech con Glassmorphism
```text
Genera un sistema de diseño en Vanilla CSS para una landing page moderna de temática Dark Tech.
Requisitos:
- Variables CSS (:root) con paleta: fondo #0B0F19, superficie #161D2F, cyan #00D2FF, azul #0051FF.
- Tipografía principal: Space Grotesk.
- Clase utilitaria para tarjetas con efecto glassmorphism (backdrop-filter: blur, bordes con opacidad sutil y sombra difusa).
- Efecto hover con resplandor neón cyan y elevación ligera.
- Botón principal con gradiente interactivo y micro-animación pulsante para el botón flotante de WhatsApp.
```

### Prompt 5: Interactividad en Vanilla JavaScript
```text
Escribe un script en Vanilla JS modular (sin frameworks externos) que contenga:
1. Efecto Typewriter para rotar 3 frases con pausas naturales.
2. Contadores numéricos que se activen únicamente cuando la sección correspondiente sea visible en la pantalla (usando IntersectionObserver).
3. Carrusel 3D estilo Coverflow que soporte navegación con teclado (flechas), botones anterior/siguiente y autoplay pausado cuando el cursor está encima.
4. Código para limpiar el logotipo/watermark de un componente <spline-viewer> accediendo a su shadowRoot de forma segura.
```
